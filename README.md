# Домашние задания по Pandas и NumPy

Этот репозиторий содержит три домашних задания, охватывающих работу с библиотеками Pandas и NumPy. В каждом файле описаны конкретные задачи и решения, выполненные в рамках учебных курсов.

---

## Структура репозитория

- **100_Numpy_exercises.ipynb** — первое домашнее задание, содержащее 100 упражнений по NumPy. В нем рассматриваются различные задачи: создание массивов, их преобразование, статистические вычисления, работа с индексами и срезами, а также практические примеры использования NumPy для анализа данных.

- **2laba** — второе задание, в котором рассматривается работа с библиотекой Pandas: загрузка данных, просмотр таблиц, фильтрация, группировка, визуализация и нормализация данных. Включает практические задачи по анализу CSV-файлов, расчету среднего значения, построению графиков и нормализации признаков.

- **3laba** — третье задание, посвященное более сложным задачам по Pandas: обработке пропущенных данных, подготовке признаков для моделей машинного обучения, обучению линейной регрессии и оценке её качества (метрики MAE, MSE, R^2). Включает примеры по подготовке данных, построению моделей и анализу ошибок.

---

## Описание задач

### 100_Numpy_exercises:
- Создание и преобразование массивов.
- Арифметические операции и статистика.
- Индексы и срезы.
- Работа с матрицами.
- Решение практических задач по анализу данных с помощью NumPy.

### 2laba:
- Загрузка данных из CSV.
- Вывод всех колонок.
- Расчет среднего значения.
- Построение графиков цен закрытия.
- Нормализация признаков.
- Расчет скользящих средних (SMA) и интерпретация графиков.

### 3laba:
- Обработка пропущенных данных.
- Подготовка признаков для модели.
- Обучение линейной регрессии.
- Оценка качества модели (MAE, MSE, R^2).
- Анализ ошибок и residuals.
